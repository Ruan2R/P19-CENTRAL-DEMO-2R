# Case de Portfólio — 2R Informática

## Resumo

O projeto 2R Informática foi criado como uma landing page institucional responsiva para demonstrar capacidade de desenvolvimento frontend, organização de interface e construção de uma experiência digital completa.

A ideia foi representar uma empresa de suporte e infraestrutura de TI sem ficar presa a uma operação real. O nome, a identidade visual e alguns serviços são baseados na 2R Informática, enquanto os cenários visuais são conceituais.

## Objetivo

Criar uma landing page que pudesse demonstrar, em um único projeto:

- construção de layout responsivo;
- organização de conteúdo;
- criação de identidade visual;
- interação com JavaScript;
- formulário com validação;
- acessibilidade básica;
- navegação mobile;
- atenção a UX e consistência visual.

## Processo

O desenvolvimento foi dividido em etapas.

### 1. Estrutura

Primeiro foi definida a arquitetura da landing page e a ordem das seções.

### 2. Conteúdo

As mensagens foram revisadas para evitar textos excessivamente genéricos e aproximar a comunicação de uma empresa real de TI.

### 3. Design

Foi criada uma linguagem visual baseada em fundo escuro, azul/ciano, bordas discretas, cards e elementos de interface conceituais.

### 4. Refinamento

O projeto passou por várias rodadas de revisão visual.

Entre os principais ajustes:

- remoção de elementos repetitivos;
- retirada da numeração excessiva dos cards;
- reorganização da seção de diferenciais;
- melhoria dos textos;
- substituição do mockup empresarial que parecia um painel de monitoramento real;
- melhoria da tipografia;
- ajustes de espaçamento;
- correções de responsividade no mobile;
- correções de overflow e de grids que mantinham regras do desktop em telas menores.

### 5. Validação

A página foi revisada em diferentes larguras, incluindo desktop, tablet e mobile, com atenção especial a:

- quebra dos títulos;
- largura dos cards;
- sobreposição com header fixo;
- fluxo vertical;
- formulário;
- footer;
- consistência do conteúdo entre dispositivos.

## Resultado

O resultado é uma landing page completa, publicada no GitHub Pages e estruturada para crescer futuramente.

🔗 https://ruan2r.github.io/P12-LANDING-PAGE-2R/

## Aprendizados técnicos demonstrados

Mesmo sendo um projeto de frontend estático, ele demonstra conhecimentos importantes de desenvolvimento web:

- semântica HTML;
- organização de CSS;
- responsividade;
- media queries;
- JavaScript para comportamento de interface;
- manipulação de classes e estados;
- validação de formulários;
- acessibilidade;
- Git/GitHub;
- deploy com GitHub Pages.

## Evolução futura

A próxima evolução natural do projeto é integrar a landing page a um sistema de O.S./chamados.

Nesse cenário, o formulário público poderia deixar de ser apenas uma demonstração frontend e passar a:

1. registrar a solicitação;
2. gerar uma O.S.;
3. encaminhar o atendimento;
4. acompanhar status;
5. alimentar um painel administrativo.

Isso transforma a landing page em uma porta de entrada para um produto de software maior.

## Posicionamento no portfólio

Este projeto representa uma etapa da transição para desenvolvimento web e foi criado com foco em demonstrar capacidade de transformar uma ideia em uma experiência digital publicada, responsiva e preparada para evolução.
