## 📚 O que foi aplicado

Durante este projeto foram praticados conceitos importantes de desenvolvimento front-end, como:

- Estruturação semântica com HTML5
- Organização e estilização de interfaces com CSS
- Flexbox e CSS Grid
- Responsividade para desktop, tablet e mobile
- Media queries
- Manipulação da DOM
- Eventos com `addEventListener`
- Menu mobile e navegação por âncoras
- Validação de formulário com JavaScript
- Estados de `hover` e `focus`
- Suporte a navegação por teclado
- Tratamento de `prefers-reduced-motion`
- SEO básico e metadados para compartilhamento
- Deploy utilizando GitHub Pages

Além da implementação técnica, a interface passou por várias etapas de refinamento visual, com foco em hierarquia, legibilidade, experiência do usuário e consistência entre desktop e mobile.

---

## 🎨 Sobre o projeto

A 2R Informática foi utilizada como base visual e conceitual para representar uma empresa de suporte, manutenção e infraestrutura de TI.

O projeto não representa uma plataforma real de monitoramento. Os painéis e interfaces exibidos na Landing Page são elementos conceituais criados para apresentar cenários e serviços de tecnologia.

A página foi construída com foco em:

- comunicação objetiva;
- identidade visual própria;
- apresentação de serviços;
- experiência do usuário;
- responsividade;
- acessibilidade;
- possibilidade de evolução para uma aplicação maior.
